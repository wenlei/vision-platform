🔗 API Bindings
端点说明
POST /detect/group/{tag}
对该 Tag 下全部设备同时抓帧，运行 YOLO 目标检测 + CLIP 自定义物品匹配。返回每台设备的 bounding box、标签、置信度及标注图路径。
POST /describe/group/{tag}
轻量版检测，不生成标注图。仅返回文字描述（如 "Detected: person, laptop"）和自定义物品匹配结果，适合轮询或文本通知场景。
POST /capture/group/{tag}
仅抓帧保存，不做任何推理。返回各设备的图片存储路径，用于截图归档或后续离线分析。
POST /detect/{name-or-mac}
对指定设备单独抓帧并完整检测，无需上传图片。支持设备名（推荐，如 desk-cam-01）或 MAC 地址，不区分大小写。适合脚本定时触发或外部服务针对某台摄像头的独立请求。
POST /detect upload
上传图片文件进行检测（form-data: file、可选 camera_ip / device_mac）。返回 detections 列表和标注图，适合 ESP32 直接 HTTP POST 原始帧。
POST /detect/all
对所有已注册设备（含 stream_url）同时抓帧并检测，不受 Tag 限制。适合一次性全局扫描。
GET /search
查询检测历史。支持参数：?label=person（按标签过滤）、?limit=50（条数）、?device_mac=…（按设备过滤）。
POST /face/identify upload
人脸识别，上传图片（form-data: file），返回匹配姓名、置信度及是否触发自适应学习。
Tag 端点绑定

在 Devices 页为设备设置 Tag，同 Tag 设备自动归组。点击路径 chip 启用或禁用该端点。
